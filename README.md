# 靶纸识别与二维云台视觉跟踪系统

本工程使用 FPGA 实现摄像头视频采集、图像处理、靶纸识别与双轴云台跟随，并包含运动区域检测、电子围栏和 HDMI 显示功能。

## 工程结构

- `project/td_project/`：Tang Dynasty 工程文件与显示时序约束。
- `project/user_source/hdl_source/`：HDL 源文件和部分器件 IP。
- `project/user_source/ip_source/`：IP 配置与生成文件。
- `project/user_source/constraints_source/`：引脚和时序约束。

## 开发环境与硬件

原工程记录的工具版本为 Tang Dynasty 6.2.168116，目标器件为 PH1P35MDG324-3。硬件包括 HX1P35A 开发板、摄像头、24 路舵机控制板、二维云台和 HDMI 显示设备。打开 `project/td_project/camera_to_dsi_display.al` 后，请检查源文件路径、IP、器件和引脚约束，并根据本地环境重新综合与布局布线。

工程不包含综合日志、布局布线中间文件或 bit 文件。清理后的工程尚未重新综合验证；软件可能重写工程文件中的项目路径。
